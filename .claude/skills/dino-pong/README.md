# Dino Pong

Agent instructions for account-owned infrastructure, batch/drip/inbound
processes, process calls, and Experience. Requires the sibling `dino-ping`
directory from the same manifest-selected bundle.

Start at [SKILL.md](SKILL.md). It routes to focused workflows and inherits
Ping's release, execution, workspace, and approval policy.

Use the native `dino` executable for production and `dino-staging` for staging.
Keep each environment's selected skill bundle and CLI installation separate.
This package contains instructions only: no runtime scripts or MCP adapters.
